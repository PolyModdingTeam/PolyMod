# PolyMod

**The mod loader for The Battle of Polytopia.**

PolyMod lets you play Polytopia with new tribes, units, buildings, skins and much more, made by the community. This site is the documentation for mod authors, for PolyMod 2.0.

## Start here

- [Introduction](docs/introduction.md): what a mod can do and where to start.
- [Your first mod](docs/getting-started.md): make a working mod in a few minutes.
- [Mod structure](docs/mod-structure.md): how PolyMod finds and loads the files of a mod.

## Reference

- [Game logic data](gld/index.md): every section and field of the game logic data that patches change.
- [GLD patching](docs/gld-patching.md): merge rules, new content and PolyMod-only fields.
- [API](xref:PolyMod): the C# API for PolyScripts.
